# 특수교사를 위한 업무수첩

학기 업무, 월·주 달력, 색 태그로 나누는 업무, 학생 카드, 개별화교육 목표와 평가 문구, 관찰 기록을 한 화면에서 정리하는 웹 도구입니다.

## 사용하기

[업무수첩 웹페이지](https://zxc3285123-web.github.io/special-education-teacher-planner/)에서 바로 사용할 수 있습니다. 홈에서 오늘·7일 안·나중에 할 일을 한눈에 보고, **나중에 할 일**의 날짜를 정해 달력으로 옮길 수 있습니다. 정한 날짜는 다시 바꾸거나 ‘나중에 할 일’로 돌릴 수 있습니다. 월 달력 **맨 왼쪽의 주 버튼**을 누르면 해당 주 일정이 열립니다. 주간 보기에서 원하는 날짜 칸을 누르면 할 일을 적을 수 있고, **한 달 달력** 버튼으로 돌아올 수 있습니다. 색 태그로 업무를 걸러 보고, **카테고리 만들기·색 바꾸기**에서 새 분류를 추가할 수 있습니다. 학생 카드에 별칭을 먼저 만들면 IEP 목표와 평가를 저장할 수 있습니다.

## HTML 파일로 전달하기

[업무수첩-공유용.html](./업무수첩-공유용.html) 파일을 내려받아 전달하세요. 받는 사람은 파일을 Chrome이나 Edge에서 열면 됩니다. 이 파일에는 화면과 기능이 모두 들어 있어 인터넷 연결이 없어도 쓸 수 있습니다. 공유 파일에는 작성자의 기록이 포함되지 않으며, 받는 사람의 입력 내용은 그 사람의 브라우저에 별도로 저장됩니다.

## 기록 보관

입력한 학생 정보와 업무 기록은 사용하는 **기기의 브라우저 저장 공간**에만 보관됩니다. GitHub에 자동으로 올라가지 않으며, 다른 브라우저나 기기로 자동 동기화되지 않습니다. 브라우저 데이터를 지우면 기록이 사라질 수 있으므로, 앱의 **설정 → 백업 파일 받기**를 이용해 주기적으로 백업하세요. 백업 파일에 학생 정보가 들어갈 수 있으니 학교에서 정한 안전한 위치에 보관하세요. 학생 이름은 별칭으로 적는 것을 권장합니다.

IEP 평가 문구는 작성 초안입니다. 실제 관찰 내용과 학교의 작성 기준에 맞는지 교사가 확인한 뒤 사용하세요.

## 구성

별도 설치나 서버가 필요 없는 단일 HTML 파일입니다. 웹페이지용 `index.html`은 Pretendard CDN을 사용할 수 있지만, `업무수첩-공유용.html`은 외부 글꼴 연결 없이 시스템 글꼴로 표시됩니다.
